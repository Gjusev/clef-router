How it works

One call to Clef,
every prompt routed

Your OpenAI client posts to /v1/chat/completions. clef-router turns the last user message into a Clef state, asks one joint question set (team + urgency), and answers with the tier decision. The completion model is yours to call, exactly like laya-router.
